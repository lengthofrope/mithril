# pyannote — Self-hosted Speaker Diarization

> **Deprecated:** This service is superseded by the unified speech service in `docker/speech/`.
> The unified service provides both transcription and diarization in a single container,
> with a default engine that requires no HuggingFace token, and optional pyannote support.
> Set `MEETING_DIARIZATION_PROVIDER=unified` to migrate. This directory will be removed in a future release.
